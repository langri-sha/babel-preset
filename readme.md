# babel-preset

The shared Babel preset for modern browsers and runtimes, and the helpers its
tests run on.

| Package                                             | Description                                                                           |
| --------------------------------------------------- | ------------------------------------------------------------------------------------- |
| [`@langri-sha/babel-preset`](packages/babel-preset) | Babel preset with support for TypeScript, Emotion and React                           |
| [`@langri-sha/babel-test`](packages/babel-test)     | Helpers for inspecting and testing a Babel preset, used by `@langri-sha/babel-preset` |
